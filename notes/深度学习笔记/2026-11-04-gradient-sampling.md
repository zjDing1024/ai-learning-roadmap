# 固定参数下的梯度估计：原创推导与官方来源

日期：2026-11-04。研究项目为 [PyTorch](https://github.com/pytorch/pytorch)，维护者为 PyTorch 团队与社区。适合阶段1：先理解梯度的对象、归一化和统计含义，再比较实际训练预算。没有复制上游实现。

## 官方来源与许可

- [2.14 autograd.grad](https://docs.pytorch.org/docs/2.14/generated/torch.autograd.grad.html)：获取对指定输入的梯度；与把梯度累积到叶子 `.grad` 的训练模式区分。本项用它测量固定参数梯度，并检查原有缓冲不变。
- [2.14 CrossEntropyLoss](https://docs.pytorch.org/docs/2.14/generated/torch.nn.CrossEntropyLoss.html)：研究 mean reduction。本项没有类别权重和忽略标签，因此分母是实际样本数；不能直接外推到加权／忽略标签场景。
- [固定官方源码与许可证](https://github.com/pytorch/pytorch/blob/5c4886908584029761b579af026dcfb627c84070/LICENSE)：PyTorch BSD-style 许可保留原声明。源码组织中 autograd 管理微分，nn 定义损失和模型接口，optim 管理更新；本项只调用前两部分，不构造优化器。
- 数据沿用 [UCI Wine](https://archive.ics.uci.edu/dataset/109/wine)，CC BY 4.0，既有来源和许可文件保留。

## 固定点上的两个不同命题

记逐样本梯度为 h_i，全训练平均梯度为 g=(1/N)Σh_i。分区批梯度 g_j 是其批内均值，因此 g=Σ(n_j/N)g_j。六个16条批次与一个11条尾批不能各占1/7；否则尾批中每条样本权重更大。该恒等式要求参数不变、损失可按样本相加。沿训练轨迹测得的不同参数点梯度不能这样合并。

从 N 个样本均匀无放回抽 b 个，单次抽样内没有重复；不同抽样之间可重叠。令 v=(1/N)Σ||h_i−g||²，展开平方范数，利用单点入选概率 b/N、双点共同入选概率 b(b−1)/(N(N−1))，得到 E||ĝ−g||²=(N−b)/(b(N−1))v。b=N 时为零。独立测试穷举小总体全部子集验证此式。

无偏是对所有可能抽样的期望而言；32次抽样的经验平均不必等于期望。经验／理论误差比不是显著性检验，不应设置一个事后阈值让实验通过。模型参数不更新，本项也没有“训练更快”“泛化更好”的结论。

## 工程沉淀

原始 JSON 保留完整参考梯度、抽样行索引、哈希和误差；独立测试捕获真实梯度张量再核对。哈希用于身份检查，不能代替数值正确性证明。下一项进入 batch size 真实训练，明确等样本访问与等更新次数是不同问题。
