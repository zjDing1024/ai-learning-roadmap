# 特征缩放与条件数：等价预测为何有不同优化轨迹

日期：2026-11-02，Asia/Kuala_Lumpur。接续学习率稳定性，研究表示变换如何改变优化几何。本文为原创推导，实际数值、验收和提交见[增量报告](../../daily-learning/2026-11-02/FEATURE_CONDITIONING.md)。

`SGD.step` 按参数组传入各组学习率，单张量更新路径将相应梯度乘以该学习率。当前实验关闭动量与 weight decay，因此可用独立闭式方程核对它的最基本更新语义。参数组允许为缩放后的斜率设置不同学习率，这提供了一个机制对照，而不需要把另一个训练框架加入项目。

## 同一个预测问题

固定五个输入 `x=[-1,-0.5,0,0.5,1]`，目标 `y=2x+0.5`。定义正尺度 `s` 与新输入 `z=sx`，模型改写为 `theta*z+b`。令原坐标斜率 `a=s*theta`，则预测仍是 `a*x+b`，最优值是 `theta*=2/s`、`b*=0.5`。

三个尺度都从 `theta=b=0` 开始，因此初始函数和初始 loss 一样。不能直接比较不同尺度下的 theta 误差或 theta 更新范数；它们使用了不同坐标。应比较原坐标斜率 `a`、偏置 `b`、样本预测、loss 和预测空间误差。

## 曲率、条件数与稳定上界

因为 `mean(x)=0`、`mean(x²)=0.5`，损失可展开为：

- `L(theta,b)=0.5*(s*theta-2)^2+(b-0.5)^2`。
- `dL/dtheta=s*(s*theta-2)`，`dL/db=2*(b-0.5)`。
- `H=diag(s²,2)`。
- `kappa=max(s²,2)/min(s²,2)`。
- 正标量学习率的全部方向严格稳定区间为 `0 < eta < 2/max(s²,2)`。

尺度 0.25、1、4 对应条件数 32、2、8，严格标量稳定上界分别为 1、1、0.125。条件数反映方向收缩速率的不均衡，但稳定上界还取决于最大特征值的绝对大小，不能仅凭条件数判断某个固定学习率是否稳定。

对原坐标误差 `e_a=a-2`、`e_b=b-0.5`，标量 SGD 递推为：

- `e_a(next)=(1-eta*s²)*e_a`。
- `e_b(next)=(1-2*eta)*e_b`。

所以相同预测函数和相同初始化，并不意味着相同标量学习率会给出相同轨迹。这是参数化改变了欧氏梯度下降使用的度量，而不是训练数据或目标发生变化。

## 三种预声明策略

固定三个尺度和每组 12 步，全部比较使用 CPU float64。

1. **shared**：两参数共享 `eta=0.15`。尺度 4 的斜率误差倍率为 -1.4，处于不稳定方向；尺度 0.25 的斜率倍率为 0.990625，下降很慢。此处保留不稳定结果，不事后缩小学习率。
2. **curvature**：共享 `eta=0.5/max(s²,2)`。所有方向的倍率均在 0 与 1 之间，本固定问题预期逐步下降；但安全不等于各尺度都以相同速度收敛。
3. **mapped**：theta 使用 `eta_theta=0.15/s²`，bias 使用 `eta_b=0.15`。映射回原坐标后，误差倍率分别为 0.85 和 0.7，与尺度 1 的 shared 基线一致。此项是对角学习率变换的受控等价性检查，不是宣称相同标量 SGD 对缩放不变。

三策略、三尺度共九个案例、108 个步骤。映射对照按预声明 `atol=rtol=1e-12` 比较原坐标参数和样本预测，不把有限精度比较写成任意环境逐位一致。解析参照在每一步独立计算，不能用两次相同训练调用代替数学验证。

## 解释边界与工程价值

此处改变的是一个固定输入的单位和参数坐标，没有训练集拟合的均值／方差估计，也没有测试集，不把它称为完整 StandardScaler 实验。若后续使用真实数据标准化，统计量只能由训练数据拟合，评估边界需另行声明。

本项用于理解预处理、优化器参数组、条件数和稳定学习率的联系。它不证明任意缩放都会改善条件数，也不推荐一个通用最优尺度；不衡量 wall time、吞吐或生产泛化，且不覆盖动量、Adam、随机批次、GPU、混合精度和分布式训练。
