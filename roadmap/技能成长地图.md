# 技能成长地图

## 2026-10-31：随机前向与恢复顺序

本轮增加 Dropout 随机前向／反向重放材料：区分参数状态、模块模式、随机流位置、输入与执行顺序；检查 CPU 默认 RNG 的临时使用与恢复。执行证据见[当日日报](../daily-learning/2026-10-31/README.md)，本项没有训练更新，也没有联合训练集成。

个人能力保持“待独立自测”。新增目标是解释为什么只存 seed 不够、恢复 RNG 后再构造 Linear 为什么可能破坏重放、为什么 no_grad 不等于 eval、为什么 fork_rng 不是线程锁；再以本人改写和故障修复记录证明理解。不能由助理实验通过推导个人具备生产训练容错或跨运行时逐位复现能力。

## 2026-10-30：联合状态与失败后拒绝继续

本轮增加数据流与训练器共同保存的工程材料：区分索引发出、梯度计算、参数更新和进度提交，失败后拒绝快照／继续，并从先前完整联合快照重放。状态范围包括待用原始梯度、实际分母、窗口计数、排列、游标、RNG、模型与 SGD。执行结果以[当日日报](../daily-learning/2026-10-30/README.md)为准，不从设计说明推断测试通过。

个人能力保持“待独立自测”。目标是独立解释为什么更新后失败不能只退游标，为什么有合法摘要的拼接状态仍可能对应错误训练历史，以及为什么恢复轨迹一致不代表外部副作用恰好一次或磁盘断电安全。受控 CPU 仿射实验的证据不外推为任意训练系统的容错能力。

## 2026-10-29：数据顺序状态与发出边界

本轮新增独立批索引流的工程材料：专属 CPU 生成器、当前排列、已发出游标、跨 epoch 恢复和 `drop_last` 边界。执行覆盖与结果以[当日日报](../daily-learning/2026-10-29/README.md)为准；无测试证据的设计目标不标为通过。

个人能力保持“待独立自测”。新增自测目标是画出 seed、生成器状态、排列与游标的关系，解释为何当前 epoch 相同仍不足以证明下一 epoch 相同；再说明索引已返回但训练尚未完成时，恢复索引流为什么不能补偿训练进度。任意 DataLoader、worker、预取、联合训练恢复、GPU / AMP / DDP 均不在本轮已验证能力范围内。

## 2026-10-28：恢复状态与安全边界

本轮增加累积窗口内恢复的工程验收材料：区分已更新的模型/动量状态与尚未应用的梯度，记录实际分母、窗口计数与数据游标，并对连续运行和恢复运行作对照。已执行范围和结果以[当日日报](../daily-learning/2026-10-28/README.md)为准，不由设计说明推定测试已经通过。

个人能力保持“待独立自测”。新增自测目标是画出一次未完成窗口的状态表，说明遗漏待用梯度或重复读取微批次如何改变下一次更新，并区分快照一致性、文件完整性与恶意文件安全。任意指令处崩溃恢复、随机层、GPU / AMP / DDP 不在本轮已验证能力范围内。

## 2026-10-27：训练循环证据增量

本轮增加梯度累积的工程验收材料：按实际目标元素数加权、处理不完整窗口、对照真实有效批次的参数与 momentum，并保留错误缩放对照。执行范围和结果以[当日日报](../daily-learning/2026-10-27/README.md)为准。

个人能力仍标记为待独立自测。新增自测目标是解释 `5+3` 尾窗口为何不能平均两个微批次均值，区分 microbatch 次数与 optimizer 更新次数，并独立构造多输出分母错误的反例。GPU / AMP / DDP、BatchNorm/Dropout 等价性与窗口中途恢复未获本轮验证。
